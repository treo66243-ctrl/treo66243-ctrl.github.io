적용 범위

이 방침은 앱 배포 파일을 보관하는 개인용 MyApps AutoRelease와 이 안내 사이트에 적용됩니다. MySecretary 또는 소절 앱 안의 사용자 기록을 Drive에 백업하는 서비스는 제공하지 않습니다.

접근하는 Google 데이터와 목적

운영자가 Google로 동의한 경우 Google Drive API의 drive.file 권한으로 이 자동화가 만든 파일과 폴더, 또는 운영자가 이 자동화에 명시적으로 열어 준 항목에 접근합니다. APK 업로드, 버전별 보관, 최신 APK 갱신과 검증을 위해 필요한 파일 콘텐츠와 파일·폴더 ID, 이름, 상위 폴더, 체크섬, 공유 상태 등 메타데이터를 읽거나 수정합니다. 다른 Drive 파일의 광범위한 조회, Gmail 접근, 광고, 프로파일링, 모델 학습에 Google 데이터를 사용하지 않습니다.

저장, 전송 및 보호

재인증 없이 작업을 실행하기 위한 OAuth 갱신 토큰과 클라이언트 정보는 비공개 GitHub Actions Secrets에 보관하며 작업 중 Google 토큰 발급 서버와 Drive API에 HTTPS로 연결합니다. 검증한 APK는 승인된 비공개 Drive 폴더로 전송합니다. GitHub Actions는 작업 실행과 비공개 빌드 산출물 전달에 사용됩니다. Drive 접근 권한을 공개로 바꾸거나 Google 사용자 데이터를 판매하거나 광고 목적으로 공유하지 않습니다. 공개 안내 페이지는 추적 스크립트나 입력 폼을 사용하지 않습니다. 페이지 제공에는 GitHub Pages의 호스팅이 사용됩니다.

보관 및 삭제

Drive의 최신 파일과 버전별 APK는 운영자가 삭제할 때까지 보관됩니다. 자동화는 이전 버전 파일을 자동 삭제하지 않습니다. 현재 릴리스 워크플로의 GitHub APK 산출물 보존 기간은 7일입니다. 연결을 해제하려면 Google 계정의 서드 파티 연결에서 MyApps AutoRelease 접근을 삭제하고, 비공개 서명 저장소에서 관련 OAuth Secrets를 삭제하세요. 이미 업로드된 파일은 Google Drive에서 별도로 삭제할 수 있습니다.

Google API 데이터 사용과 문의

Google API에서 받은 정보의 사용과 이전에는 Google API 서비스 사용자 데이터 정책의 제한된 사용 요건을 적용합니다. 문의나 데이터 삭제 요청은 Google OAuth 동의 화면에 표시되는 사용자 지원 이메일로 보낼 수 있습니다.
